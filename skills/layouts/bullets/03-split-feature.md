Left 40%: full-height image with one stat or kicker overlaid on it. Right 60%: bullets
as compact mini-cards with icon badges, staggered x-offsets so rows don't form a flat
list.

IMAGE OVERLAY — CRITICAL: if you darken the image for text legibility, the overlay
rectangle MUST cover the ENTIRE image (identical x, y, width, height to the image) so
the tone is uniform. NEVER place a partial overlay over only part of the image — a
half-height or half-width scrim leaves a hard seam straight across the artwork and looks
broken. Better still for an illustration on a colored field: skip the full-image scrim
entirely and set the overlaid stat/kicker on its own small solid chip (a little filled
rounded rectangle behind just the stat), leaving the illustration clean.
