Magazine-cover feel: an ULTRA-large display title (72-92pt) set low-left against
generous whitespace, a top metadata rule (letterspaced section / date / edition split by
thin vertical dividers), a hairline baseline grid (2-3 thin rules), a small corner
monogram or logotype, and one restrained accent mark. Imagery optional and muted.
Premium through scale + emptiness. Target 14-18 elements.
